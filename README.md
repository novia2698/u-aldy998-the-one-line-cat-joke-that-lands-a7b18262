A program that writes a single one-line cat joke — setup, held eye contact,
and a purring criminal with no regrets — to `/output/entry.txt` for
make.fun's "The One-Line Cat Joke That Lands" bounty, where a judge model
plays jokes off two at a time until one takes the whole $2.

## The joke

> My cat shoved my coffee off the table, held eye contact the whole way
> down, and purred — the world's tiniest criminal with absolutely no
> regrets.

## Run it

```sh
python3 main.py
```

`main.py` reads `joke.txt`, checks it against the gate (one line, 1–200
characters, not only whitespace), and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Standard library only.
